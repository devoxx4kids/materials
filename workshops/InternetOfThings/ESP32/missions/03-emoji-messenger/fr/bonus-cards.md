# Mission 3 : cartes bonus 🃏

---

## 🃏 Carte A : Code secret

**But :** envoyer un mot secret que seuls tes partenaires peuvent lire.

**Comment :** utilise le nombre comme clé. Avant d'envoyer, remplace chaque lettre de ton mot par la lettre 3 places plus loin (A → D, B → E). Ceux qui reçoivent font l'inverse. Utilise **joindre** et les lettres d'un mot une par une.

**Conseil pour le coach :** c'est le chiffre de César. Laissez-les d'abord le faire sur papier.

---

## 🃏 Carte B : Canaux d'équipe

**But :** passer du groupe de ta table à un groupe commun pour toute la salle.

**Comment :** le cercle de droite fait déjà le tour de tous les emojis, donc le cercle de gauche est libre. Change ton script **bouton gauche touché ?** : ajoute une variable `groupe` ; si `groupe` est ton numéro de table, mets-le à `99`, sinon remets-le à ton numéro de table. Puis lance **espNow définir le groupe** avec `groupe` et affiche-le avec **joindre** `Groupe ` **et** **groupe**.

**Conseil pour le coach :** mettez-vous d'accord sur un seul numéro de groupe commun en plus pour toute la salle.

---

## 🃏 Carte C : Livraison de prédictions 🎱

**But :** envoyer une réponse de la boule magique à une autre table.

**Comment :** ajoute la liste de réponses de la mission 1. Choisis une réponse **au hasard** et envoie-la comme texte de la paire (avec le nombre 9, par exemple). La carte qui reçoit affiche le texte quand le nombre est 9.

**Conseil pour le coach :** le binôme qui reçoit doit ajouter un test pour 9 avant le test des emojis.
